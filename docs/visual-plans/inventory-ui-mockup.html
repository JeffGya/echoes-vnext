            Grounding and limits

            The tile, marks, gauge, sockets, chip, strip and modal styles are copied from mockups/v1/shared/items.css and adapted inline. Fonts are system fonts here, so the look is close but not identical to the sheets. The 1920 profile is drawn on the 1536 logical canvas, as in the static sheets (scale 1.2 on the chrome, tile 72).

            The path view, the board and the EchoBar are stand-ins. The real chrome is drawn from the scene files, as in the static sheets. Sound and haptic items are hints only: the project has no audio layer.

            Item data, the intake rule, the early-leave draw and the path-end rule are small prototype rules. They do not read the game's core code.
