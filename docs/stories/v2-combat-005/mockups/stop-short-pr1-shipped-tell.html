Animation (V46) - Normal, Slow, Fast

Real board proportions. Each loop: before, walk ends, dip, hop, landing, ripple, marker pop, rest pose, long rest, status ends (fade, return). The label strip names the phase. Numbers: feel file V46 (proposal). Slow is Normal x 1.6. Fast has no dip and no shake, hop 10, pose 0.06 s, no ripple. The rest (3 s) is a demo length: in play it lasts as long as the status. V47: the Guard arc moves with the body during the lean, so it never looks detached. The arc appears at landing, so the hop does not move it. It keeps the HP bar cut and leans with the bar. The Hold ring does not move. The marker lasts as long as the pose (assumed). Observe has no dip and no pose.

If your system asks for reduced motion, the loops do not play. They show the rest frame. Press Play to see the motion.
