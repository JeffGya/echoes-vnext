  • Ekwan appears 3 times (row, “Sanctum share” row, chip). Proposed: its own small ledger with one total.

So the three screens do not show the same rows. They share one row design and one tooltip. Only the cause ids differ. If you want a earnings when a whole realm ends, that is a new design decision. The code has none now.

Open point: today the objective and stage payers both earn Ase for the same fight (enemies + echoes on the objective; objective weights on the stage). The player may ask “why did I earn twice?”. The stage tooltip for “Objectives overcome” should say it is a separate stage earnings. This is a wording question for Jeff.

Hover alone is not enough on a phone, so the tooltip also opens on tap. The same tap pattern already exists in EchoRankBenefitGlyph. A screen reader reads the row label, the amount, then “Why?”.
