- Probe scripts, all in `probe/`: `patch_l3.py` applies every timer, `TimingProbeAcc.gd.txt` is the accumulator the patch needs, and
  `run_profile.sh <patch.py> <tag> [suite]` patches, runs ONE suite, restores `core/`, `tests/` and `ui/` with `git checkout`,
  and prints the `TPROF` / `TCOUNT` lines. Example: `GODOT_BIN=/path/to/godot probe/run_profile.sh patch_l3.py baseline fingerprint_guide_spirit`.
  The script finds the repository from its own location, needs unchanged tracked files in `core/`, `tests/` and `ui/`, and rejects a run
  that has no `Tests: N total, N passed, 0 failed` line (the runner exits 0 even when it fails).
