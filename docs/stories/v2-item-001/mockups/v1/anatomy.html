Item tile anatomy, V2-ITEM-001a

Written by the artist. One ItemTile for eight surfaces. Shared stylesheet: shared/items.css. Sections 1 to 8, then the 1280x720 canvas. Player text is a grey bar or [Jeff's wording]. Forbidden colours in section 1 appear only to be crossed out. No item mark uses them.

1. Swatches, measured contrast and forbidden colours

Contrast is my own WCAG calculation. The design-system file states gold on panel 4.8:1 (measured 1.72:1) and tan 5.2:1 (measured 3.66:1). Gold marks always carry an ink keyline. No new tokens.

4. Twin test

Two twins: same type, same grade. Colour row, grayscale row, 3x row. Pair A differs by notch (n1 and n4). Pair B has the same notch and the same state: the worst case, about 1 in 6 pairs, accepted risk A2. Pair C has the same notch but one twin is carried (leaf and darker bed).
